# 计件月结

管理端入口为 `/settlement/`。系统管理员、财务可按归属月份查询。财务只读；锁账和解锁必须由启用的系统管理员操作。

1. 选择归属月份，查看已审核报工的试算、员工金额、辅助分钟和报工明细。员工筛选只影响页面显示。
2. 处理提示中的进行中生产任务、辅助作业、待审核记录或无法分配的报工。管理员核对整月结果后确认锁账；提交时若数据或锁账版本已变更，系统要求重新核对。
3. 锁账后可导出整月 Excel，含“员工汇总”和“计件明细”两张表。导出读取本次锁账快照，文件名含月份和版本编号，工号与文本按字符串存储。未锁月份和没有计件快照的旧月份不导出正式结果。工作簿使用 [openpyxl](https://pypi.org/project/openpyxl/) 生成。
4. 补审须由管理员填写原因解锁。解锁保留原计件快照及锁账事件，辅助工时按既有规则清除当前汇总。复核并再次锁账后生成新计件版本与辅助工时汇总。下载提供当前有效的锁账版本。

## 已确认的计算规则

- 只纳入归属月审核通过的报工。有效完工数量取最新的数量修正，单价用报工冻结单价。每条报工先算金额，按四舍五入保留到分。单人金额归报工人。
- 整组先算总额，再按每人全部冻结在组时段的秒数占比向下取分。剩余的分全部给原派工名单第一位，小组长移交不改变尾差归属。例如三人等工时分配 13.75 元，第一位 4.59 元，另外两位各 4.58 元。
- 正金额的整组报工如果冻结工时合计为零，或者冻结在组记录缺失，会提示具体报工并阻止锁账。金额、工时均为零且在组记录完整时可锁账。第一期不含扣款和补贴。
- 辅助工时只汇总已审核分钟；优先用修正后的有效分钟，不计金额。整组明细中的有效数量为整组报工总量，不应跨员工重复加总。

## 数据与验证

`PieceworkAllocation` 按锁账事件、报工和员工唯一保存金额（整数分）、有效数量、冻结单价、归属日、冻结在组秒数及工号／姓名／工单／工序。期间状态、锁账事件、计件明细和辅助工时汇总在同一事务中写入。解锁不覆盖原计件明细。

迁移 `settlement/0004` 只新增明细表和锁账事件的快照标记。旧锁账状态与原始报工保留，旧月份明确提示缺少快照；由管理员按原流程解锁、复核、重新锁账后生成，不做批量补算。

全量 194 项测试通过。隔离库验证了旧版本迁移、跨月夜班、组员多次在组与移交、四舍五入、尾差、零工时拒绝、权限、旧版本拒绝、事务回滚及导出回读。浏览器完成了试算、锁账、下载，演示金额 38.75 元与辅助工时 60 分钟在页面和 Excel 中一致。正式数据库并发尚待试点验收。
