# 工时计件系统 · 一期设计

本文只记录已经约定的规则，给实现对照。没写到的口径保持开放，不要在代码里补一套未经约定的制度。

## 1. 一期范围

一期做四件事：

- 车间固定终端报工
- 班组长派工与班组审核
- 月结结算与按月锁定
- 从易飞每 5 分钟拉取未结工单

工序档案是上面四件事的前置数据，一期要能维护。

## 2. 角色与权限

按角色授权。

| 角色 | 职责 |
| --- | --- |
| 车间工人 | 在固定终端识别身份，选择已派给自己的任务，开工、完工，录入完工数量 |
| 班组长 | 派工；做班组审核，可修改最终完工数量 |
| 月结结算（人资 / 财务） | 按月结算计件工资，执行月锁定 |
| 工艺人员 | 维护工序档案（单价、标准工时）和工艺路线 |

工人使用车间固定终端。终端认人两种方式都要支持：NFC / 工牌刷卡，以及扫描员工二维码。工牌丢失时可用员工二维码进入终端。

## 3. 主流程

1. 工艺人员维护工序档案。每个产品有多道工序，每道工序有单价和标准工时。工艺路线在本系统维护。
2. 系统每 5 分钟从易飞 9.012 拉取未结工单。工单来自易飞。
3. 班组长按工单上的工序把任务派给工人。
4. 工人在终端刷卡或扫码后，从已派任务中选择任务。并行工序的任务可以同时开工。
5. 开工、完工在终端打卡。实际工时由开工、完工时间自动计算。
6. 工人录入完工数量并提交。提交时把该工序当时的单价冻结到这条报工上。
7. 班组长审核：检查完工数量是否合理，并把实际工时与标准工时对照。可以修改最终完工数量。工人提交的原始报工必须保留。
8. 月结结算按「合格件数 × 报工时冻结的单价」计算。该月还有未审核报工时不能锁定。锁定后，该月报工不能再改。

## 4. 硬规则

- **计件工资** = 合格件数 × 单价。完工数量与合格件数是同一口径。单价在报工提交时冻结。已派未报工任务的单价仍在报工时冻结，不以派工时为准。之后工序档案改价，已报工记录和结算结果保持冻结价。计件金额保留两位小数，到分。
- **工作中心多人同工序**：经工作中心由多人完成同一工序时（例如冲压），计件工资先按整个工作中心小组计算，再在小组成员之间平均分配。
- **实际工时不进入计薪公式。** 工时来自开工、完工打卡，供班组审核对照标准工时。
- **并行开工**允许。并行工序任务可以同时处于开工状态。重叠的实际工时在对照标准工时之前，按这些并行任务平均分摊。
- **审核留痕。** 班组长可以改最终完工数量，不能覆盖工人原始报工。原始记录与审核后的最终数量都要留下。
- **月锁定是一期必做。** 该月存在未审核报工时，拒绝锁定。锁定之后，该月报工不可修改。
- **易飞只读。** 对接易飞 9.012，每 5 分钟拉取一次未结工单。不把计件数量、工时、金额回写易飞。
- **派工数量**不能超过工单剩余量，超出时硬拦截。
- **完工数量超出派工**：报工完工数可以超过派工数量。审核时明确提醒，通过后方可生效。
- **暂停**：开工后可以暂停。暂停时段不计工时，且必须填写暂停原因。
- **反审核**：月结锁账前允许反审核，且需要更高权限。
- **自派自审**：第一期允许班组长自派自审。
- **终端在线**：终端必须在线才能开工报工。
- **月结查询与导出**：月结支持导出 Excel，也要系统内查询。

## 5. 数据边界

- **工单**：易飞未结工单的只读同步结果，每 5 分钟拉取一次。
- **工序档案 / 工艺路线**：本系统维护。工序至少包含单价、标准工时。
- **派工**：班组长将工序任务派给工人。工人报工时只能从已派任务里选择。
- **报工**：对应一条已派任务。记录开工时间、完工时间、自动算出的实际工时、工人录入的完工数量、报工时冻结的单价，以及原始报工内容。审核若修改数量，最终完工数量另行保存。
- **员工主数据**：在本系统维护。
