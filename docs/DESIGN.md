# 工时计件系统 · 一期设计

本文只记录已经约定的规则，给实现对照。没写到的口径保持开放，不要在代码里补一套未经约定的制度。

## 1. 一期范围

一期做这些事：

- 车间固定终端报工
- 班组长派工与班组审核
- 辅助工时登记、审核，并计入月结
- 月结结算与按月锁定
- 从易飞每 5 分钟拉取未结工单
- 从易飞只读拉取生产入库，按工单对照每一道工序的报工数量

工序档案是上面这些事的前置数据，一期要能维护。第一期不做派工超时提醒。月结按归属月份汇总已审核通过的报工，并按员工汇总已审核通过的辅助工时。辅助工时只汇总工时，第一期不算金额。第一期不含扣款、补贴等调整项。

## 2. 角色与权限

按角色授权。

| 角色 | 职责 |
| --- | --- |
| 车间工人 | 在固定终端识别身份，选择已派给自己的任务，开工、完工，录入完工数量；可查看本人本月和上月的计件明细（含未审核、已驳回等状态）；审核前可撤回未审核报工并重报；驳回后修改数量重新提交审核 |
| 班组长 | 派工；做班组审核，可修正工时或完工数量，须填写原因并保留原始报工 |
| 月结结算（人资 / 财务） | 按归属月份汇总已审核通过的报工，结算计件工资 |
| 工艺人员 | 维护工序档案（单价、标准工时）和工艺路线 |
| 系统管理员 | 执行月结锁账；锁账后可解锁，解锁须填写原因并留痕 |

工人使用车间固定终端。终端认人两种方式都要支持：NFC / 工牌刷卡，以及扫描员工二维码。工牌丢失时可用员工二维码进入终端。登录后 15 秒无操作自动退出。工人可刷卡或扫员工二维码查看自己的计件明细，范围为本月和上月，含未审核、已驳回等状态。

## 3. 主流程

1. 工艺人员维护工序档案。每个产品有多道工序，每道工序有单价和标准工时。工艺路线在本系统维护。单价、标准工时修改保存即生效，之后的报工使用新值；每次修改留历史。
2. 系统每 5 分钟从易飞 9.012 拉取未结工单。工单来自易飞。同步到工单已关闭后，已派任务仍可报完，但不能再对该工单新派工。
3. 班组长按工单上的工序把任务派给工人。整组计件（多人同一工序，例如冲压）派工时列出组员，第一位默认为小组长。
4. 工人在终端刷卡或扫码后，从已派任务中选择任务，也可查看本人本月和上月的计件明细（含未审核、已驳回等状态）。登录后 15 秒无操作自动退出。并行工序的任务可以同时开工。整组任务由小组长在终端代整组开工；组员在整组任务期间不能同时开别的任务。
5. 开工、完工在终端打卡。实际工时由开工、完工时间自动计算，计时以服务端开工时刻为准。终端断网不影响已开工任务的计时，恢复联网后再报工；开工、报工等操作仍必须在线。下班后须报完工。工人忘记报工、下班后任务仍开着时，不自动停表，继续计时，由班组长审核时修正工时。整组计件的组员工时从小组长开工算到报工；中途加入或离开由小组长代为登记，并按登记时刻截断。小组长暂停即全组暂停。小组长中途离开前，须先把小组长身份移交给组内另一人。
6. 工人录入完工数量并提交。提交时把该工序当时的单价冻结到这条报工上。整组计件由小组长代整组报工。审核前可撤回未审核报工并重报，撤回时必须选择或填写原因。
7. 班组长审核：检查完工数量是否合理，并把实际工时与标准工时对照。可以修正工时或完工数量，都必须填写原因，并保留报工原始记录；也可以驳回。驳回后由工人修改数量后重新提交审核，保留原始记录与驳回记录。
8. 月结按归属月份汇总已审核通过的报工，按「合格件数 × 报工时冻结的单价」计算。第一期不含扣款、补贴等调整项。整组计件先算整组金额，再按各组员实际工时占比分配，分配不尽的尾差给派工时列出的第一位。同一归属月还要按员工汇总已审核通过的辅助工时，只计分钟，不算金额。报工和辅助工时都按归属日计入月份：整段夜班归属开班日，月末白班下班报当日完工，月末跨日夜班仍归属开班日所在月份。月结锁账由系统管理员执行。该月还有未审核报工或未审核辅助工时时不能锁账。锁账后该月报工和辅助工时不能再改。系统管理员可解锁，须填写原因并留痕；解锁后可按既有规则修改，再重新锁账。

## 4. 硬规则

- **计件工资** = 合格件数 × 单价。完工数量与合格件数是同一口径。单价在报工提交时冻结。已派未报工任务的单价仍在报工时冻结，不以派工时为准。单价、标准工时修改保存即生效，之后的报工使用新值；报工时冻结的单价规则不变，已报工记录和结算结果保持冻结价。计件金额保留两位小数，到分。
- **整组计件**：经工作中心由多人完成同一工序时（例如冲压），派工时列出的第一位组员默认为小组长，由他在终端代整组开工和报工。组员中途加入或离开，由小组长在终端代为登记；组员工时从小组长开工算到报工，中途加入或离开按登记时刻截断。整组计件金额按各组员实际工时占比分配，全程在组且无变动时等同于均分。金额保留到分，分配不尽的尾差给组内第一个人，即派工时列出的第一位。小组长暂停即全组暂停，暂停时段全组都不计工时，暂停仍须填写原因。小组长中途离开前，须先在终端把小组长身份移交给组内另一人。组员在整组任务期间不能同时开别的任务，整组任务不适用并行任务规则。
- **实际工时不进入计薪公式。** 工时来自开工、完工打卡，计时以服务端开工时刻为准，供班组审核对照标准工时。终端断网不影响已开工任务的计时。工人忘记报工、下班后任务仍开着时不自动停表，继续计时，由班组长审核时修正工时。整组计件的总额仍按合格件数 × 单价计算，再按各组员实际工时占比分配。
- **并行开工**允许。并行工序任务可以同时处于开工状态。重叠的实际工时在对照标准工时之前，按这些并行任务平均分摊。整组任务不适用本条；组员在整组任务期间不能同时开别的任务。
- **审核留痕。** 班组长审核时可以修正工时或完工数量，都必须填写原因，并保留报工原始记录。不能覆盖工人原始报工。驳回后由工人修改数量后重新提交审核，保留原始记录与驳回记录。
- **月结与锁账。** 月结按归属月份汇总已审核通过的报工，并按员工汇总该归属月已审核通过的辅助工时。辅助工时只汇总工时，第一期不算金额；单价、金额字段可以留空，不参与这次计算。第一期不含扣款、补贴等调整项。锁账由系统管理员执行；该月存在未审核报工或未审核辅助工时时，拒绝锁账。锁账后该月报工和辅助工时不可修改。系统管理员可解锁，解锁须填写原因，并记录解锁人、时间、原因。解锁后可按既有规则修改，再重新锁账。
- **辅助工时。** 归属日、班次归属、审核和锁账与计件报工同一套。审核通过后计入该员工的归属月工时。有修正时用修正后的分钟，原始分钟保留。
- **入库与报工对照。** 生产入库从易飞只读拉取，不回写。对照时用工单的入库数量，和该产品每一道工序的报工数量分别比较。每道工序都要给出审核通过的数量，以及全部未撤回报工的数量。易飞表名和字段先做成可配置映射，具体值待核对。
- **易飞只读。** 对接易飞 9.012，每 5 分钟拉取一次未结工单。不把计件数量、工时、金额回写易飞。同步到工单已关闭后，已派任务仍可报完，但不能再对该工单新派工。
- **派工数量**不能超过工单剩余量，超出时硬拦截。
- **完工数量超出派工**：报工完工数可以超过派工数量。审核时明确提醒，通过后方可生效。
- **暂停**：开工后可以暂停。暂停时段不计工时，且必须填写暂停原因。整组计件中，小组长暂停即全组暂停，暂停时段全组都不计工时。
- **反审核**：月结锁账前允许反审核，且需要更高权限。
- **自派自审**：第一期允许班组长自派自审。
- **终端在线**：开工、报工等操作必须在线。终端断网不影响已开工任务的计时，计时以服务端开工时刻为准；恢复联网后再报工。
- **终端退出**：登录后 15 秒无操作自动退出。
- **计件明细**：工人可在终端刷卡或扫员工二维码查看自己的计件明细，范围为本月和上月，含未审核、已驳回等状态。
- **月结查询与导出**：月结支持导出 Excel，也要系统内查询。
- **归属日**：白班/夜班起止时间按工作中心配置。班组默认继承所属工作中心的班次，也可单独覆盖。整段夜班的报工都归属开班日（例如 10/31 晚至 11/1 早的夜班报工归属 10/31）。下班后须报完工。月末白班下班报当日完工，月末跨日夜班仍归属开班日所在月份。
- **报工撤回**：审核前，工人可撤回未审核的报工并重报。撤回时必须选择或填写原因。撤回后原派工任务回到可再报状态，已报数量额度恢复。

## 5. 数据边界

- **工单**：易飞未结工单的只读同步结果，每 5 分钟拉取一次。同步到工单已关闭后，已派任务仍可报完，但不能再对该工单新派工。
- **工序档案 / 工艺路线**：本系统维护。工序至少包含单价、标准工时。单价、标准工时修改保存即生效，之后的报工使用新值；报工时冻结的单价规则不变，已报工的不受影响。每次修改留历史，记录修改人、修改时间、旧值和新值。
- **班次**：白班/夜班起止时间按工作中心配置。班组默认继承所属工作中心的班次，也可单独覆盖。
- **派工**：班组长将工序任务派给工人。工人报工时只能从已派任务里选择。整组计件须按顺序列出组员，第一位默认为小组长。
- **报工**：对应一条已派任务。记录开工时间、完工时间、自动算出的实际工时、工人录入的完工数量、报工时冻结的单价，以及原始报工内容。开工时刻以服务端为准。审核若修正工时或完工数量，须填写原因，修正值另行保存，并保留报工原始记录。撤回须选择或填写原因。驳回须保留驳回记录。整组计件由小组长代整组报工，并登记组员中途加入或离开的时刻。
- **员工主数据**：在本系统维护。
- **辅助工时**：本系统登记。月结只收已审核通过的分钟，按员工和归属月汇总。
- **生产入库**：易飞只读镜像。和报工的差异按工序展开，不只看末道工序。
- **月结锁账**：由系统管理员执行。解锁须留痕，记录解锁人、解锁时间、原因。
